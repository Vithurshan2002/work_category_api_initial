WORK CATEGORY API - INITIAL STRUCTURE

Python files are intentionally empty. Add the code from the tutorial.
Open this work-category-api folder itself in VS Code.
The training folder must remain directly inside the project root.

Setup from the VS Code terminal:
uv init
uv python pin 3.12
uv add fastapi uvicorn pandas scikit-learn joblib

Add labeled rows to data/raw/service_requests.csv.
After adding tutorial code and sufficient data:
uv run python -m training.prepare_data
uv run python -m training.train_model
uv run python -m training.evaluate_model
uv run python -m uvicorn app.main:app --reload

Processed CSV files and the trained model are generated by the scripts.
pyproject.toml and uv.lock are generated by uv.
